# Sentinel AI

AI-powered environmental and local-hazard intelligence assistant. It combines Open-Meteo weather/air/elevation data, USGS earthquakes, a deterministic flood-risk engine, saved places, alerts, demo scenarios, photo preview, and a replaceable local AI tool-agent.

## Run

```bash
npm install
npm run dev
```

## Build/Test

```bash
npm test
npm run build
```

No API keys are required for the live data sources currently used. A remote AI/vision provider is intentionally optional and not configured by default.
